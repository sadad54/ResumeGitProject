# packages/evals

Evaluation dataset schema + harness (PRD §26). Retrieval metrics (Recall@K, MRR/nDCG)
seeded in Phase 4; requirement-extraction F1, unsupported-claim rate, parse-back
success rate, and cost/latency reporting added as their corresponding pipelines land.
Grown from the fixture JD(s) to the full 100+ labeled JD benchmark in Phase 9.

Never include private user data in this package or its datasets (PRD §26.1).
